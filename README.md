# Lyrics Filler 自动填词

MuseScore Studio 4.x 的自动填词插件：把歌词复制到剪贴板，它按语言规则切成音节，
顺序填进你选定声部的音符下方。中文一字一音，英文按连字符分音节，
连音线上的多个音符只填第一个字（一字多音）。

**不联网** —— 歌词和乐谱全程只在你本机处理。

最新变化见 [CHANGELOG.md](CHANGELOG.md)；下载入口在
[Releases](https://github.com/rogerwang2008/musescore-chinese-lyrics-filler/releases/latest)。

## 30 秒上手

1. 到 [Releases](https://github.com/rogerwang2008/musescore-chinese-lyrics-filler/releases/latest)
   下载 `LyricsFiller-vX.Y.Z.zip`，解压，把里面的 **`LyricsFiller` 文件夹**
   整个放进 `文档\MuseScore4\Plugins`（macOS / Linux 是 `~/Documents/MuseScore4/Plugins`）。
2. **完全退出 MuseScore 再重新打开。**
3. 复制歌词 → 选中要填词的音符 → 菜单 **插件 → 歌词 → Lyrics Filler 自动填词**
   → 点 **统计** 看一眼数量对不对 → 点 **应用**。

不满意就 **Ctrl+Z**，一次撤销整批写入。

## 安装

### 方式一：下载发布包

上面"30 秒上手"就是这个方法，也是推荐的安装方式。

### 方式二：用仓库里的脚本

Windows 双击 `install.bat`；macOS / Linux：

```bash
./install.sh
```

脚本会把 `LyricsFiller/` 整个目录复制到默认用户插件目录：

```
Windows   <文档>\MuseScore4\Plugins\LyricsFiller
macOS     ~/Documents/MuseScore4/Plugins/LyricsFiller
Linux     ~/Documents/MuseScore4/Plugins/LyricsFiller
```

> Windows 上"文档"经常被重定向（OneDrive，或者整个搬到别的盘）。
> 脚本会先查注册表拿到**真实**的文档目录，并把它打印成 `Target` —— 请以屏幕上那行为准。
> 想装到别处就直接传参数：`install.bat "D:\Music\MuseScore4\Plugins"`。

### 确认装好了

重启后菜单 **插件 → 歌词** 里能看到 "Lyrics Filler 自动填词"；
或在 **插件 → 管理插件** 里搜名字。找不到请看[常见问题](#常见问题)。

### 版本兼容

在 **MuseScore Studio 4.7.5** 上开发并实测。4.x 的其他版本理论上可用，
但延音线（Slur）识别未在其他版本验证过；万一读不到，插件会退回只认连音线（Tie）
并在状态栏明确提示你，不会静默出错。

## 使用

1. **复制歌词**到剪贴板。Word、网页、记事本里复制的纯文本都可以。
2. **选中要填词的范围**（拖选一小节到几小节，或点谱表左侧选中整条谱表）。
   不选也行 —— 默认按整条谱表处理。
3. 打开 **插件 → 歌词 → Lyrics Filler 自动填词**，歌词会自动出现在输入框里。
4. 点 **统计**。状态栏会告诉你：识别成哪种语言、多少个音节单元、多少个音符、
   其中多少个是连音/延音的后续音、差多少。
5. 数字对得上就点 **应用**。

**填第二段歌词**：复制新歌词 → 重开插件 → 把"第几段歌词"改成 2 → 应用。
多段歌词就是一段一段填，插件不会自己按空行分段。

**改错了想退回**：一次 **Ctrl+Z** 撤销整批写入（所有改动包在同一个撤销命令里）。
中途出错会自动回滚，不会留下填了一半的谱子。

## 分词规则

### 中文 / 一字一音（默认）

| 输入 | 结果（每一项 → 一个音符） |
| --- | --- |
| `床前明月光` | 床 / 前 / 明 / 月 / 光 |
| `床前明月光，` | 床 / 前 / 明 / 月 / `光，`（逗号跟着"光"走，仍是 5 个单元） |
| `床前 明月\n光` | 空白和换行都不占音符 |
| `[测试]你好` | `测试`（只占 1 个音符）/ 你 / 好 |
| `唱la la吧` | 唱 / `la` / `la` / 吧（夹带的英文按整词走） |

汉字范围包含简体、繁体、兼容表意文字，以及平假名和片假名（日文歌词同样一字一音）。

### 英文

| 输入 | 结果 |
| --- | --- |
| `Silence is golden` | Silence / is / golden（三个音符，都没有连字符） |
| `re-action` | `re` + `action`，谱面上自动显示成 `re-action` |
| `in-com-pre-hen-si-ble` | 6 个音符 |
| `Si - lence` / `re- action` / 跨行的 `ev-\nery` | 连字符两侧的空格和换行不影响拆分 |
| `sing [test word] now` | sing / `test word`（1 个音符）/ now |
| `Singin' in the "rain"` | Singin' / in / the / `"rain"` |

连字符不用你自己画：插件写入的是 MuseScore 的原生"音节"属性，
**连字符由软件排版本时自己补**，所以换行、改字体之后位置仍然正确。
手动把 `-` 留在歌词文本里会出现两条连字符。

### 标点符号

标点**不占音符，也不会被丢掉**，而是自动贴到相邻的歌词上：

| 情况 | 归属 | 例子 |
| --- | --- | --- |
| 字后面的标点 | 贴回前一个字 | `霜。` 显示在同一个音符下 |
| 连续多个标点 | 全部并到前一个字 | `了！??` → 一个音符 |
| 词前的引号、括号 | 贴到下一个字前面 | `“你好”` → `“你` + `好”` |
| 方括号单元后面 | 贴到该单元末尾 | `[la la]吧！` → `la la` + `吧！` |

因为标点不产生新单元，**加不加标点都不影响与音符的对位**。

唯一的例外是连字符 `-`：它是英文的音节边界，贴进歌词会被当成文字，所以永远丢弃。
想要"延长"效果请用下面的延长线选项，而不是打一排破折号。

### 方括号：让多个字挤进一个音符

`[测试]`、`[test word]` 里的内容整体算**一个**音节单元，只占一个音符。
内容原样保留（连续空白会压成一个空格），可以放标点和英文。
用来对付"一个字对应一个词"的情况，比如把 `消防栓` 写成 `[消防栓]` 挤进一个音。

### 语言自动识别

数一下文本里汉字和拉丁字母谁多，谁多就用谁的语言规则；打平按中文。
识别结果显示在状态栏，判断不对时手动切到"中文"或"English"即可。

## 一字多音（连音线与延音线）

- **连音线（Tie）**：同音高相连。有向后进线的音符一律留空，只在第一个音填字。
- **延音线（Slur）**：整条弧线覆盖的音符段落，同样只在首音填字，其余留空。

两者都只在"首音"消耗一个音节。可以各自用开关关掉。

勾上 **为连音段画延长线** 后，首音的歌词会带上覆盖整段的延长线：

```
床 ——————————————————
```

> **一点音乐上的提醒**：slur（连奏线）在常规记谱里只是"连贯地唱"，
> 每个音通常各自有歌词；把 slur 当一字多音处理并不通用。
> 插件默认按这个方式做，但它是**一个开关**。
> 如果你的谱子里 slur 只是连奏标记，请取消勾选"延音线只填首音"，
> 否则会出现后半段音符没词的情况。

装饰音（倚音、颤音等）不占歌词，会被跳过并在状态栏告诉你跳了几个。
休止符同样不消耗音节。

## 选项说明

| 选项 | 默认 | 作用 |
| --- | --- | --- |
| 语言 | 自动识别 | 强制按中文或英文规则分词 |
| 第几段歌词 | 1 | 写到第几段（verse），多段歌词逐段填 |
| 谱表 / 声部 | 跟随选区 | 目标谱表与声部；打开插件时会用当前选区预填 |
| 只填选区 | 开（有选区时） | 关掉就处理整条声部 |
| 连音线只填首音 | 开 | 关掉后连音线的每个音各吃一个音节 |
| 延音线只填首音 | 开 | 见上一节的提醒 |
| 为连音段画延长线 | 关 | 在首音歌词上画覆盖整段的延长线 |
| 已有歌词 | 覆盖 | 选"跳过该音符"会保留原来的歌词不动 |
| 位置 | 自动 | 只在选"上方/下方"时才改歌词位置，否则用软件默认 |
| 数量不一致时不应用 | 关 | 开启后音节数与音符数不等就直接中止，不写入 |

## 示例

**中文，6 个音符**，第 3、4 个音由连音线相连（同音高延续），所以能填歌词的位置只有 5 个。

```
[测试]床前明月
```

分词结果是 `测试`、`床`、`前`、`明`、`月` 共 5 个单元，正好对上：

| 音符 | 1 | 2 | 3 | 4 | 5 | 6 |
| --- | --- | --- | --- | --- | --- | --- |
| 与下一音 | | | 连音线 → | | | |
| 歌词 | 测试 | 床 | 前 | *（留空）* | 明 | 月 |

**英文，4 个音符**，无连音线。

```
re-action [test word] go
```

| 音符 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- |
| 歌词文本 | `re` | `action` | `test word` | `go` |
| 谱面显示 | re- | action | test word | go |

第 1、2 个音之间的连字符由 MuseScore 自己补，文本里并不含 `-`。

## 常见问题

**菜单里找不到插件**
- 确认复制过来的是 `LyricsFiller` **文件夹**，完整路径形如
  `...\MuseScore4\Plugins\LyricsFiller\lyricsfiller.qml`（不是把 .qml 单独丢在 Plugins 下）。
- 检查 **编辑 → 偏好设置 → 扩展** 里的"我的插件"目录，必须和你实际放的目录一致。
  Windows 上"文档"被重定向时，`C:\Users\<你>\Documents` 往往不是 MuseScore 读的那个。
- **完全退出 MuseScore 再打开**。插件列表里的 "Reload plugins" 不会加载改过的代码。

**提示"剪贴板是空的或不含文本"**
- 有些来源（图片、部分富文本）不含纯文本。直接把歌词粘贴到输入框就行，效果一样。
- Linux 下个别剪贴板管理器需要额外装 `wl-clipboard`（Wayland）或 X11 剪贴板支持。

**填到了别的声部 / 位置整体不对**
- 多声部谱表要先在"声部"里选对（1–4 对应 Voice 1–4）。
- 用 **统计** 先看：音节数和音符数接近，说明目标声部找对了。

**音节比音符多或者少**
- 状态栏会给出确切差值。音节多了就删掉多余的；
  音符多了先检查是不是"延音线只填首音"把一批音符吃掉了。
- 需要严格一一对应时，勾上"数量不一致时不应用"，对不上就不写入。

**歌词显示成了 `re-` 这样多了一条横线**
- 说明文本里原本就带了连字符。把 `-` 删掉，让插件用音节属性来排（见
  [英文](#英文)一节）。

**想撤回**
- 一次 **Ctrl+Z**。所有写入包在同一个撤销命令里。

## 已知限制

- **一次只处理一条谱表的一个声部**，不能一次把 4 段歌词分派到 4 条谱表。
- **换行不当作段落分隔**，多段歌词请逐段填（配合"第几段歌词"）。
- 方括号 `[...]` 不支持嵌套，也不建议和相邻文字连写（`la[xx]` 会被当成一个词）。
- 英文不处理省音（elision，如 `l'amor` 之间的那种连音线），需要时请手动加。
- 极生僻字（Unicode 平面 2 以上，如 𠀀）不在汉字范围内，会被当成标点贴到前一个字上
  （`月𠀀` 挤进同一个音符）。需要它独占一个音符时，用方括号包起来：`[𠀀]`。
- 休止符上不写歌词（MuseScore 里歌词挂在休止符上属于异常状态）。
- 标点只是"贴"在歌词文本上，不参与发音或排版判断。想让某个标点单独占一拍，
  那它本来就该是一个音符，请用方括号把它包成一个单元。

## 隐私与 AI 使用

**插件完全离线。** 它只做三件事：读剪贴板、切音节、把结果写进你打开的乐谱。
代码里没有网络请求，没有遥测，不上传歌词或乐谱的任何部分，也不会保存剪贴板内容。
整个插件就是一个 `lyricsfiller.qml` 文件，可以自己打开读完 —— 这是刻意的设计。

**开发过程使用了 AI 辅助。** 代码是在 AI 结对编程下完成的。但 MuseScore 的 QML 插件
API 文档很少，AI 的"常识"在这个领域错过若干次（例如延音线的检测方法、界面复选框
不会自己翻转、内部时值的换算基数）。所有这类结论都不是照搬 AI 的说法，
而是在 MuseScore Studio 4.7.5 上逐项实测验证过的，并且写成了回归测试防止回退。
踩坑记录集中在 [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)。

**歌词版权请你自己确认。** 插件不生成歌词，只搬运你剪贴板里的文本。
如果你用 AI 写词，请留意所用服务的授权条款以及你的发行平台要求。
本仓库不包含受版权保护的歌词或乐谱样本。
