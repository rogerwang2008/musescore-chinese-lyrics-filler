# Lyrics Filler 自动填词

MuseScore Studio 4.x 的自动填词插件。从剪贴板读取歌词，按语言规则切分为音节单元，
顺序填入选定声部的音符下方。中文一字一音，英文按连字符分音节，
连音线（Tie）与延音线（Slur）覆盖的音符只在首音填词。

插件不联网，歌词与乐谱均在本机处理。更新记录见 [CHANGELOG.md](CHANGELOG.md)。

## 快速开始

1. 从 [Releases](https://github.com/rogerwang2008/musescore-chinese-lyrics-filler/releases/latest)
   下载 `LyricsFiller-vX.Y.Z.zip`，解压后将 `LyricsFiller` 文件夹放入
   `文档\MuseScore4\Plugins`（macOS / Linux 为 `~/Documents/MuseScore4/Plugins`）。
2. 退出并重新启动 MuseScore。
3. 复制歌词 → 选中目标音符 → 菜单 **插件 → 歌词 → Lyrics Filler 自动填词**
   → **统计** 核对数量 → **应用**。

一次 **Ctrl+Z** 撤销整批写入。

## 安装

### 发布包

即[快速开始](#快速开始)第 1–2 步。

### 脚本

Windows 运行 `install.bat`，macOS / Linux 运行 `./install.sh`。
脚本将 `LyricsFiller/` 复制到默认用户插件目录：

```
Windows   <文档>\MuseScore4\Plugins\LyricsFiller
macOS     ~/Documents/MuseScore4/Plugins/LyricsFiller
Linux     ~/Documents/MuseScore4/Plugins/LyricsFiller
```

Windows 的"文档"目录常被重定向（OneDrive 或其他磁盘），此时
`%USERPROFILE%\Documents` 并非 MuseScore 实际扫描的目录。脚本先读取注册表
`User Shell Folders\Personal` 取得真实路径，并在输出中打印 `Target`，以该行为准。
自定义目标：

```
install.bat "D:\Music\MuseScore4\Plugins"
./install.sh "D:/Music/MuseScore4/Plugins"
```

### 版本兼容

在 MuseScore Studio 4.7.5 上开发与实测。4.x 其他版本未验证延音线识别：
读不到延音线时插件仅按连音线处理，并在状态栏提示。

## 使用

1. 复制歌词到剪贴板（Word、网页、记事本等来源的纯文本均可）。
2. 选中填词范围：拖选若干小节，或点击谱表左侧选中整条谱表。未选中时按整条谱表处理。
3. 打开 **插件 → 歌词 → Lyrics Filler 自动填词**，歌词自动填入输入框。
4. 点 **统计**，状态栏显示识别语言、音节单元数、音符数、连音/延音后续音数量及两者差值。
5. 点 **应用** 写入。

多段歌词需逐段填写：复制新歌词 → 重开插件 → 修改"第几段歌词"序号 → 应用。
换行不作为段落分隔。

所有写入包在同一个撤销命令内，一次 Ctrl+Z 全部回退；写入过程出错时自动回滚。

## 分词规则

### 中文 / 一字一音（默认）

| 输入 | 结果（每项对应一个音符） |
| --- | --- |
| `床前明月光` | 床 / 前 / 明 / 月 / 光 |
| `床前明月光，` | 床 / 前 / 明 / 月 / `光，` |
| `床前 明月\n光` | 空白与换行不占音符 |
| `[测试]你好` | `测试` / 你 / 好 |
| `唱la la吧` | 唱 / `la` / `la` / 吧 |

汉字范围包括 CJK 统一表意文字（含扩展 A）、兼容表意文字、平假名与片假名。

### 英文

| 输入 | 结果 |
| --- | --- |
| `Silence is golden` | Silence / is / golden |
| `re-action` | `re` + `action`，谱面显示为 `re-action` |
| `in-com-pre-hen-si-ble` | 6 个音符 |
| `Si - lence`、`re- action`、`ev-\nery` | 连字符两侧的空格与换行不影响拆分 |
| `sing [test word] now` | sing / `test word` / now |
| `Singin' in the "rain"` | Singin' / in / the / `"rain"` |

写入时不含 `-`，改用 MuseScore 的原生音节属性（begin / middle / end / single），
连字符由软件排版时绘制，位置随字体与换行自动调整。手动保留 `-` 会产生双连字符。

### 标点

标点不占音符，也不被丢弃，而是并入相邻歌词：

| 情况 | 归属 | 示例 |
| --- | --- | --- |
| 字后标点 | 并入前一个字 | `霜。` 显示于同一音符下 |
| 连续多个标点 | 全部并入前一个字 | `了！??` 为一个单元 |
| 词首引号、括号 | 并入下一个字 | `“你好”` → `“你` + `好”` |
| 方括号单元之后 | 并入该单元 | `[la la]吧！` → `la la` + `吧！` |

标点不产生新的音节单元，因此音节总数不变，与音符的对位不受影响。

例外是连字符 `-`：它是英文的音节边界标记，不并入歌词。延长效果请使用延长线选项。

### 方括号

`[测试]`、`[test word]` 内的内容合并为一个音节单元，只占一个音符。
内容原样保留（连续空白压缩为一个空格），可包含标点与英文。

### 语言自动识别

统计 CJK 字符数与拉丁字母数，取较多的一方；相等时按中文。
结果显示在状态栏，可手动改为"中文"或"English"。

## 一字多音

- **连音线（Tie）**：同音高相连。存在向后进线的音符一律留空，仅在首音填词。
- **延音线（Slur）**：整条弧线覆盖的音符段落同样仅在首音填词。

两者均由首音消耗一个音节，可分别用开关关闭。

启用 **为连音段画延长线** 后，首音歌词带有覆盖整段的延长线：

```
床 ——————————————————
```

延音线的处理方式是可选项而非定论：常规记谱中 slur 表示连奏，各音通常各有歌词。
若谱中 slur 仅作连奏标记，请关闭"延音线只填首音"，否则该段落后续音符将无歌词。

装饰音（倚音、颤音等）不占歌词，跳过时状态栏给出数量。休止符不消耗音节。

## 选项

| 选项 | 默认 | 作用 |
| --- | --- | --- |
| 语言 | 自动识别 | 强制按中文或英文规则分词 |
| 第几段歌词 | 1 | 写入的 verse 序号 |
| 谱表 / 声部 | 跟随选区 | 目标轨道；打开插件时按当前选区预填 |
| 只填选区 | 开（有选区时） | 关闭后处理整条声部 |
| 连音线只填首音 | 开 | 关闭后连音线的每个音各占一个音节 |
| 延音线只填首音 | 开 | 见[一字多音](#一字多音) |
| 为连音段画延长线 | 关 | 在首音歌词上绘制覆盖整段的延长线 |
| 已有歌词 | 覆盖 | 选"跳过该音符"时保留原歌词 |
| 位置 | 自动 | 仅在选"上方/下方"时修改歌词位置 |
| 数量不一致时不应用 | 关 | 音节数与音符数不等时中止写入 |

## 示例

**中文，6 个音符**，第 3、4 音由连音线相连，可填位置为 5 个。

```
[测试]床前明月
```

分词结果为 `测试`、`床`、`前`、`明`、`月` 共 5 个单元：

| 音符 | 1 | 2 | 3 | 4 | 5 | 6 |
| --- | --- | --- | --- | --- | --- | --- |
| 与下一音 | | | 连音线 → | | | |
| 歌词 | 测试 | 床 | 前 | *（留空）* | 明 | 月 |

**英文，4 个音符**，无连音线。

```
re-action [test word] go
```

| 音符 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- |
| 歌词文本 | `re` | `action` | `test word` | `go` |
| 谱面显示 | re- | action | test word | go |

第 1、2 音之间的连字符由 MuseScore 绘制，歌词文本中不含 `-`。

## 常见问题

**菜单中没有插件**

- 确认复制的是 `LyricsFiller` 文件夹，路径形如
  `...\MuseScore4\Plugins\LyricsFiller\lyricsfiller.qml`。
- 核对 **编辑 → 偏好设置 → 扩展** 中的"我的插件"目录与实际放置目录一致。
  Windows 上"文档"被重定向时，`C:\Users\<用户>\Documents` 通常不是 MuseScore 读取的目录。
- 重启 MuseScore。插件列表中的 "Reload plugins" 只重扫列表，不加载修改后的代码。

**提示"剪贴板是空的或不含文本"**

来源不含纯文本时（图片、部分富文本），直接将歌词粘贴到输入框。
Linux 下部分剪贴板管理器需要 `wl-clipboard`（Wayland）或 X11 剪贴板支持。

**填到其他声部，或位置整体偏移**

多声部谱表需先在"声部"中选择正确轨道（1–4 对应 Voice 1–4）。
用 **统计** 核对：音节数与音符数接近，说明目标声部正确。

**音节数与音符数不符**

状态栏给出确切差值。音节偏多时删减歌词；音符偏多时检查"延音线只填首音"
是否吸收了过多音符。要求严格对应时启用"数量不一致时不应用"。

**歌词出现多余连字符**

歌词文本中包含了 `-`。删除后由插件通过音节属性排版。

## 已知限制

- 一次仅处理一条谱表的一个声部，不能将多段歌词分派到多条谱表。
- 换行不作为段落分隔。
- 方括号不支持嵌套，且不与相邻文字连写（`la[xx]` 会被识别为一个词）。
- 不处理英文省音（elision，如 `l'amor`），需手动添加。
- Unicode 平面 2 以上的生僻字（如 𠀀）不在汉字范围内，会并入前一个字。
  需其独占一个音符时用方括号包裹：`[𠀀]`。
- 不在休止符上写歌词。
- 标点仅并入歌词文本，不参与发音或排版判断。

## 隐私与 AI 使用

**离线运行。** 插件仅执行三项操作：读取剪贴板、切分音节、写入当前乐谱。
不含网络请求与遥测，不上传歌词或乐谱，不保留剪贴板内容。
实现集中在单个 `lyricsfiller.qml` 文件，可直接审计。

**开发过程使用 AI 辅助。** 代码在 AI 结对编程下完成。MuseScore 的 QML 插件 API
文档稀少，AI 的先验知识在多处不适用（延音线的检测方式、界面复选框的行为、
内部时值的换算基数）。相关结论均在 MuseScore Studio 4.7.5 上逐项实测，
并写成回归测试。记录见 [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)。

**歌词版权由使用者确认。** 插件不生成歌词，仅处理剪贴板中的文本。
使用 AI 生成歌词时，需自行核对所用服务的授权条款与发行平台要求。
本仓库不包含受版权保护的歌词或乐谱样本。
